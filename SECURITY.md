# Security policy

## Reporting a vulnerability

Please report security problems in Imadia (the desktop app or its website) privately, through
[GitHub's private vulnerability reporting](https://github.com/Shauden-356/Media-Render/security/advisories/new),
not in a public issue. Include what you found, how to reproduce it, and the version (Help › Version in the app).

## Supported versions

Only the latest release gets fixes. The app installs updates automatically.
