Sign-in cookies

Download as your logged-in self: for YouTube's "confirm you're not a bot", members-only or age-restricted videos, and sites that need an account. Cookies stay on this computer, and each one is only sent to the site it belongs to.

Not using cookies.
Read fresh each time, so it follows your sign-ins. On Windows, close Chrome, Edge or Brave first. On a Mac, allow the "Safe Storage" request if asked; Safari needs Full Disk Access.
Export it with an extension such as "Get cookies.txt LOCALLY" (Chrome, Edge) or "cookies.txt" (Firefox). Anyone with this file can sign in as you: keep it private.

These three work on YouTube and other sites yt-dlp supports.
